# סרטוני סטטוס מונפשים — בשפת המותג של אפרת כהן

הסקיל משלב שני דברים:
1. **הדקדוק של סרטון הרפרנס** (פרסומת "סדנת ק(ל)וד קוד"): מבנה, קצב, מעברים ואפקטים שהופכים 30 שניות לסרטון שעוצר גלילה. הפירוט ב-`references/style-guide.md`.
2. **המותג של אפרת כהן**: אספרסו, קרם, חול וזהב, טיפוגרפיה צרה וגבוהה, קשתות שיש, מסגרות זהב דקות ואייקון הלוגו האדריכלי. הפירוט ב-`references/brand.md`.

הכלל: **הקצב והאנרגיה מהרפרנס, המראה מהמותג.** הוורוד של הרפרנס הופך לזהב, והסוגריים של ק(ל)וד הופכים לאייקון הלוגו ולקשת.

## מה יש בתיקייה
```
assets/template.html   מנוע אנימציה + סרטון לדוגמה (עורכים רק את SCENES)
assets/fonts/          Karantina (כותרות) + Assistant (טקסט), רישיון OFL
assets/brand/          לוגו (מסכות לצביעה חופשית), מנורה ושולחן זהב בלי רקע
scripts/render.mjs     ייצוא ל-MP4 / צילום פריים בודד
references/style-guide.md   ניתוח הרפרנס: מבנה, קצב, ספריית אפקטים
references/brand.md         פלטה, פונטים, מוטיבים, קול המותג
```

## תהליך עבודה

### 1. בריף (שאלה אחת מרוכזת, רק על מה שחסר)
- מה מקדמים? (שירות, הצעה, סדנה, פרויקט, טיפ)
- מה הקריאה לפעולה? (שאלון, וואטסאפ, טלפון, הרשמה)
- יש תמונות או הדמיות של פרויקטים? בלי תמונות עובדים עם רקעי צבע, קשתות שיש, קווי שרטוט ואלמנטי הזהב שב-`assets/brand/`.
- אורך: ברירת מחדל 20–30 שניות.

### 2. תסריט: שבע פעימות
| פעימה | זמן (ל-30ש׳) | תפקיד |
|---|---|---|
| קרס | 0–3 | שאלת כאב שהלקוח מזהה ("לפני שיפוץ?") |
| הבטחה | 3–6 | מה משתנה ("הבית שחלמתם מתחיל במבט אדריכלי") |
| חשיפה | 6–10 | המסר המרכזי במשפט קצר וגדול ("בשטח רואים אחרת") |
| הצעה / הוכחה | 10–15 | מספר, יתרון או תוצאה, עם המחשה ויזואלית |
| מונטאז' | 15–19 | 5–7 מילים בודדות, כל אחת כ-0.45ש׳, רקע מתחלף |
| הרגעה | 19–22 | רגע שקט על קרם: "פשוט", "בלי התחייבות", הסלוגן |
| קריאה לפעולה | 22–30 | לוגו + כפתור + פרטים, **הכי הרבה זמן על המסך** |

כללי כתיבה: מקסימום 6–7 מילים בכל מסך. בכל מסך מילה **אחת** בזהב. עברית מדוברת, חמה ובטוחה, בלי סלנג.

### 3. סטוריבורד
לפני הקוד מציגים למשתמשת טבלה: זמן | טקסט על המסך | רקע | ויזואל | אפקט כניסה | מעבר החוצה. מחכים לאישור או לתיקונים. שינוי בטבלה זול, שינוי ברינדור יקר.

### 4. בנייה
1. יוצרים תיקייה לסרטון (למשל `videos/<שם>/`) ומעתיקים אליה את **כל** תוכן `assets/` (הנתיבים לפונטים וללוגו יחסיים).
2. משנים את שם `template.html` ל-`video.html` ועורכים **רק** את `window.makeScenes`. כל סצנה: `{at, dur, bg, html, anim(t,q)}`.
3. משתמשים באפקטים מ-`fx` (רשימה מלאה עם פרמטרים ב-style-guide):
   `rise`, `type`, `pop`, `drop`, `fade`, `underline`, `draw`, `count`, `arch`, `iris`, `zoomWipe`, `kenburns`, `flip`.
   `dimOut` רץ אוטומטית בסוף כל סצנה. `dim:false` מבטל אותו.
4. תמונות של המשתמשת: מעתיקים לתיקיית הסרטון ומכניסים עם `<img>` במיקום מוחלט. תמונה כהה מקבלת מעבר הדרגתי לאספרסו באזור הטקסט, כדי שהטקסט יישאר קריא.

### 5. בדיקה לפני ייצוא מלא
```bash
node scripts/render.mjs videos/x/video.html /tmp/check.png --still 8.5
```
מצלמים 6–10 רגעים: אמצע כל סצנה וכל מעבר. מסתכלים על התמונות ובודקים קריאות, חפיפות, טקסט שיוצא מהמסגרת וכיוון RTL. מתקנים ורק אז מייצאים.

### 6. ייצוא
```bash
node scripts/render.mjs videos/x/video.html videos/x/out.mp4 [--audio music.mp3]
```
התוצאה: 1080x1920, ‏30fps, ‏H.264, מוכן לסטטוס. 30 שניות לוקחות כדקה וחצי. אם יש מוזיקה, מיישרים את ה-`at` של הסצנות לביטים (הרפרנס חותך על המכות).

תצוגה מקדימה חיה: פותחים את `video.html` בדפדפן. רווח עוצר, וחיצים קופצים בחצי שנייה.

## צ'קליסט איכות (חובה לפני מסירה)
- [ ] הקרס מובן בלי סאונד תוך שנייה וחצי
- [ ] שלושה צבעי מותג לכל היותר במסך, וזהב רק על המילה החשובה
- [ ] כל מעבר בנוי מאלמנט שכבר על המסך (אייקון, קשת, קו), לא fade גנרי
- [ ] הקצב משתנה: איטי ← מהיר (מונטאז') ← שקט ← CTA עומד 3 שניות ומעלה
- [ ] הטקסט בתוך אזור בטוח: 150px מלמעלה ומלמטה, 80px מהצדדים
- [ ] הלוגו מופיע בסוף בגרסה המלאה, עם הסלוגן שכבר בתוכו
- [ ] בודקים את הפריים האחרון: הוא משמש כ"פוסטר" אם הסרטון נעצר

אם המשתמשת מבקשת קובץ לעריכה ב-After Effects, Canva או CapCut, מוסרים את **הסטוריבורד** עם ערכי ה-easing והתזמונים מ-style-guide (הם תקפים בכל תוכנה) במקום לרנדר.
